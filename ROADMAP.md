# Syncfusion Blazor Toolkit Roadmap

## Vision

Build the fastest-to-adopt open-source Blazor UI toolkit with:

- Zero configuration
- Native Blazor architecture
- Production-ready charts
- Excellent accessibility
- Strong developer experience

Our focus is to expand application-building capabilities while keeping the Toolkit lightweight, simple, and easy to adopt.

# Guiding Principles

### Zero Configuration

No manual CSS or JavaScript setup required.

### Accessibility First

All components should include:

- Keyboard navigation
- Screen reader support
- WCAG-aligned behavior

### Quality Over Quantity

Prioritize:

- Component quality
- Performance
- Documentation
- Developer experience

### Community Driven

Roadmap priorities will continue to evolve based on GitHub issues, discussions, and community feedback.

### Syncfusion Ecosystem Alignment

The Toolkit complements the commercial Syncfusion suite and provides a natural upgrade path for advanced enterprise scenarios.

---

# Success Metrics

By early 2028, the Toolkit aims to:

- Deliver comprehensive coverage across forms, navigation, feedback, layout, and visualization scenarios.
- Become a strong open-source choice for Blazor developers.
- Achieve competitive component breadth while maintaining its zero-configuration experience.
- Differentiate through simplicity, accessibility, performance, and developer productivity.

# Quarterly Reviews

The roadmap will be reviewed and updated quarterly based on:

- Community feedback
- Adoption metrics
- Usage trends
- Open-source contributions
- Product strategy priorities
