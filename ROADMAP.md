# Syncfusion Blazor Toolkit Roadmap

This roadmap lists the components and capabilities planned for the Syncfusion Blazor Toolkit, with target delivery dates from November 2026 to February 2027.

**Last updated:** November 2026

> **Note:** This roadmap reflects current plans. Target dates are estimates, not commitments, and may change based on quality, community feedback, and product strategy.

To see what is available today, browse the [component documentation](https://blazor.syncfusion.com/documentation/toolkit/overview) and the [live demos](https://blazor.syncfusion.com/demos/toolkit/).

## Vision

Build an open-source Blazor UI toolkit that is quick to adopt, with:

- Minimal setup
- Native Blazor architecture
- Production-ready charts
- Excellent accessibility
- A strong developer experience

The Toolkit focuses on expanding application-building capabilities while staying lightweight, simple, and easy to adopt. Chart remains the flagship component, and quality comes before breadth.

## Guiding principles

### Minimal setup

You don't add separate CSS or JavaScript references. The Toolkit ships the styles and any JavaScript it needs, and loads scripts on demand based on the functionality you use. You register the Toolkit once in `Program.cs`.

### Accessibility first

Every component includes:

- Keyboard navigation
- Screen reader support
- WCAG 2.2 Level AA-aligned behavior

### All interactive render modes

Components support Blazor Server, Blazor WebAssembly, and Blazor Auto render modes.

### Quality over quantity

The Toolkit prioritizes:

- Component quality
- Performance
- Documentation
- Developer experience

### Community driven

Roadmap priorities evolve based on [GitHub issues](https://github.com/syncfusion/blazor-toolkit/issues), [discussions](https://github.com/syncfusion/blazor-toolkit/discussions), and community feedback.

### Syncfusion ecosystem alignment

The Toolkit complements the [commercial Syncfusion Blazor suite](https://www.syncfusion.com/blazor-components) and provides a natural upgrade path for advanced enterprise scenarios.

## Out of scope

The Toolkit does not plan to provide:

- A Data Grid or any grid family
- Feature parity with the commercial Syncfusion Blazor suite
- AI chat or tool-calling components

## Success metrics

By early 2027, the Toolkit aims to:

- Offer 50+ components that cover forms, navigation, feedback, layout, and data visualization.
- Add Pie and Donut series to Chart.
- Meet WCAG 2.2 Level AA across all components.
- Keep setup to a single registration line, with no separate CSS or JavaScript references.

## Quarterly reviews

- Product strategy priorities
